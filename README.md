### Защита состояния Hero

Почему методы ПР №2 не защищали от прямой записи в поле:\
так как публичные поля позволяли присвоить любые значения в `Program.cs`

Чем отличаются get, set и private set:\
`get` позволяет получить значение поля, а `set` установить, но `private set` непозволяет установить значения из вне

Где проверяется начальное здоровье:\
начальное здоровье проверяется в конструкторе класса

Как Heal сохраняет границу MaxHealth:\
метод проверяет значение передавемое в `Heal` больше или равно разницы `MaxHealth` и `Health`, и если да присваивает `Health` значение `MaxHealth`

Как Name использует поле \_name и значение value:\
`_name` хранит имя, при попытке получить значение из `Name` возвращает его, при присваивании передает в `value`, значение `value` проверяется, если проверка не прошла `Name` возвращает значение по умолчанию, если прошла, `Trim()` удаляет лишние пробелы у `value` и присваивает его `_name`

Почему в конструкторе используется Name = name:\
так как при присваивании значения происходит проверка
