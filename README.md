## Практическая 2

### Вопросы

1. Метод экземпляра - это действие, которое выполняет объект класса.\
   `TakeDamage()`
2. Значение передается в круглых скобках и присваивается параметру.\
   `yaroslav.TakeDamage(25);`
3. `void` это объявление метода, который ничего не возвращает.\
   `public void TakeDamage(int damage)`
4. `return;` завершает выполнение метода, не возвращая значение, а `return Health > 0` возвращает значение типа bool.\

```csharp
if (damage <= 0) {
            return;
        }
        Health -= damage;
        if (Health < 0) {
            Health = 0;
        }
```

5. `bool` возвращает true/false. Ответ `IsAlive()` сохраняется в переменную.\
   `bool yaroslavAlive = yaroslav.IsAlive();`
6. `GetInfo()` формирует информацию о герое, а `Console.WriteLine()` в Program.cs выводит значение.\
   `Console.WriteLine(artem.GetInfo())`
7. Потому что метод работает с одним конкретным экземпляром класса.\
   `yaroslav.GainExperience(25);`
8. Можно изменить значение `Health` на любое.\
   `yaroslav.Health = -5000;`

1. Запрет внешней записи отличается от проверки доступности числа, тем что при попытке передачи числа запрещает изменять свойство напрямую, а проверка допустимого значения проверяет соответствует ли число установленным ограничениям. Здоровье проверяется в конструкторе класса, а его изменения в методах `TakeDamage()` и `Heal()`
2. Снчала имя передается в параметр `name`, дальще присваивается `Name = name`, `Name` прередаетс в `value`, после проверки и удаления пробелов `value` передается в `_name`
3. Начальное здоровье -100: `Health = 0`, `MaxHealth = 100`, 5000: `Health = 200`, `MaxHealth = 200`, лечение 5000: `Health = 150`, `MaxHealth = 150`, -20: `Health = 130`, `MaxHealth = 150`, урон 5000: `Health = 0`
