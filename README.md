Здоровье проверяется в конструкторе класса, а его изменения в методах `TakeDamage()` и `Heal()`
2. Снчала имя передается в параметр `name`, дальще присваивается `Name = name`, `Name` прередаетс в `value`, после проверки и удаления пробелов `value` передается в `_name`
3. Начальное здоровье -100: `Health = 0`, `MaxHealth = 100`, 5000: `Health = 200`, `MaxHealth = 200`, лечение 5000: `Health = 150`, `MaxHealth = 150`, -20: `Health = 130`, `MaxHealth = 150`, урон 5000: `Health = 0`

### Защита состояния Hero

Почему методы ПР №2 не защищали от прямой записи в поле:\
так как публичные поля позволяли присвоить любые значения в `Program.cs`

Чем отличаются get, set и private set:\
`get` позволяет получить значение поля, а `set` установить, но `private set` непозволяет установить значения из вне

Где проверяется начальное здоровье:\
начальное здоровье проверяется в конструкторе класса

Как Heal сохраняет границу MaxHealth:\
метод проверяет значение передавемое в `Heal` больше или равно разницы `MaxHealth` и `Health`, и если да присваивает `Health` значение `MaxHealth`

Как Name использует поле \_name и значение value:\
`_name` хранит имя, при попытке получить значение из `Name` возвращает его,  при присваивании передает в `value`, значение `value` проверяется, если проверка не прошла `Name` возвращает значение по умолчанию, если прошла, `Trim()` удаляет лишние пробелы у `value` и присваивает его `_name`

Почему в конструкторе используется Name = name:\
так как при присваивании значения происходит проверка

## Дополнительные вопросы
1. Полю `Health` можно было присвоить любое значение меньше 0
2. `{ get; set; }` не ограничивает присваивание значений из вне
3. `private` у всего свойства не позволяет получать и изменять значение у свойства из вне, а `private set` запрещает только изменение значений вне класса
4. Так как `private set` позволяет присваивать значения в классе, а `Program.cs` является внешним кодом по отношению к классу
5. Так как при передачи значений в конструктор и метод лечения можно указать любое значение
6. Имя храниться в поле `_name`, `value` значение, которое получает данные при передачи их свойству, `Trim()` удаляет пробелы в начале и конце строки
7. Так как само поле `_name` просто хранит имя и не проверяется через свойство `Name`
8. При помощи проверки между передаваемым значением и разностью `Health` и `MaxHealth`, если значение больше разности, то `Health = MaxHealth`
9. Проверка названия песни, исполнителя, альбома, проверка года в диапозоне от 1600 до 2026, проверка не превышает ли количество лайков лимит `int`
